# Кубики — очистка линий

Браузерная головоломка: перемещайте цветные кубики и заполняйте строки или столбцы. Полные линии исчезают, разрезая большие блоки на подвижные части. Реализация на HTML, CSS и JavaScript, без сборки.

[Играть онлайн](https://eliasnikitin777.github.io/grid-cube/) · [Репозиторий](https://github.com/eliasnikitin777/grid-cube)

Откройте `index.html` в браузере — установка и подключение к интернету не нужны. Для локального просмотра в Codex: `npm start` в этой папке, затем http://127.0.0.1:4192.

- Поле 9:16 с полупрозрачной квадратной сеткой 18×32.
- 29 кубиков разных цветов, размером от 1×1 до 6×6: восемь 1×1, восемь 2×2, шесть 3×3, четыре 4×4, два 5×5 и один 6×6. Начальная раскладка не содержит пересечений.
- Каждый кубик плавно перетаскивается пальцем, мышью или стилусом, с сохранением точки захвата. Кубики остаются непрозрачными. Под активным кубиком клетки будущей позиции окрашиваются полупрозрачным цветом этого кубика; подсветка соответствует его размеру. При отпускании кубик встаёт точно в подсвеченное место; подсветка исчезает.
- Все кубики остаются внутри поля, включая отпускание за его границами. Перемещение одного не сдвигает остальные. Занятые клетки нельзя занимать: проверяется вся площадь кубика. Во время перетаскивания подсвечивается ближайшая свободная позиция по расстоянию до кубика; учитываются все допустимые позиции на поле. Если две позиции одинаково близки, текущая подсветка сохраняется. При отпускании кубик встаёт в подсвеченное место, даже если непосредственно под пальцем занято. Кубик плавно следует за пальцем, а итоговые позиции всегда остаются без пересечений. Стрелки клавиатуры тоже не позволяют войти в занятые клетки.
- Отменённый жест, потеря фокуса и изменение размера экрана возвращают кубик в положение до жеста. Второе касание не перехватывает управление.
- Для клавиатуры: Tab выделяет кубик, стрелки перемещают его на одну ячейку, Escape отменяет активное перетаскивание.
- Выделение нескольких блоков: зажмите левую кнопку мыши на свободном месте поля и протяните рамку. Блоки, пересекающие рамку, получают белую обводку; выделение сохраняется после отпускания. Новая рамка заменяет выделение, клик по пустому месту снимает его. Escape, отмена указателя или изменение размера экрана отменяют рамку и восстанавливают предыдущее выделение. Рамка также работает пальцем. При разрезании выделенного блока его оставшиеся части сохраняют обводку.
- После отпускания блока полностью заполненные строки и столбцы исчезают, независимо от цвета. Все полные линии проверяются и удаляются одновременно, включая пересечения. Также правило срабатывает после успешного хода стрелкой клавиатуры; при отмене жеста удаления нет.
- У большого кубика удаляются только клетки внутри очищаемых линий. Остатки сохраняют цвет и положение, без падения или сдвига поля. Отдельные части становятся независимо подвижными прямоугольниками; их новые размеры учитываются в подсветке, поиске свободного места и проверке столкновений. Последующие линии могут разрезать эти части снова. Целиком удалённый блок исчезает.
- Удаление обозначается короткой вспышкой линии. На поле нет надписей, счётчиков или кнопок управления. Название и описание доступны через средства доступности.

Параметры сетки, размеры, цвета и начальные позиции кубиков заданы в `index.html`; состояние и обработка ввода — в `game.js`, оформление — в `style.css`. Квадраты используют `data-size`, для прямоугольников можно задать `data-width` и `data-height`. Чтобы сохранить квадратные ячейки на поле 9:16, выбирайте число столбцов и строк в той же пропорции.

Проверка в браузере: выполните `npm ci`, затем `npx playwright install chromium`, запустите локальный сервер и выполните `npm run test:browser`. На macOS также можно использовать установленный Google Chrome; другой путь можно задать через `CHROME_PATH`. Для проверки опубликованной версии задайте `PROTOTYPE_URL=https://eliasnikitin777.github.io/grid-cube/`. Проверяются все 29 начальных кубиков, плавное движение и ближайшее свободное место, выделение рамкой, горизонтальные и вертикальные линии, несколько линий и их пересечения, частичное и полное удаление, повторное разрезание, независимое перемещение прямоугольных частей, отмена и клавиатура. Мобильная эмуляция проверяет реальные события касания, разрезание и перемещение частей на разных размерах экрана. Отдельно проверяется работа из локального HTML-файла. Снимки до и после удаления линии на обычной раскладке и отчёт сохраняются в `outputs/`.

GitHub Pages публикует содержимое корня ветки `main`. Обновления игры становятся доступны после отправки коммита в эту ветку. Файл `.nojekyll` позволяет раздавать файлы напрямую.
